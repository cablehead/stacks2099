# v0.6.1

## Highlights

Two new HTTP routes reach past the clip/stack protocol to the machine the server runs on. `GET /file/<absolute-path>` reads a file's raw bytes; `POST /exec` runs a request body as Nushell code in a fresh subprocess and answers with `{stdout, stderr, exit_code}` as JSON. Both have the same reach a pty already has -- arbitrary read/write/execute as the server's user, no sandboxing -- so a script or an LLM gets a clean request/response shape instead of having to drive a terminal through a VT100 stream. `GET /api` on a running instance is self-describing and served live, with the full reference and worked examples -- point an LLM at `<host>/api` and it can take it from there.

Zoom mode now reflows the floated terminal to fill the viewport instead of keeping its original grid dimensions, and a redundant window resize listener was dropped since the pane observer already covers it.

New terminals now inherit the working directory of the terminal they were opened from, rather than always starting at the server's cwd.
