# v0.3.0

## Highlights

**Live terminal, server-rendered.** The terminal streams to the browser as row-by-row diffs with a separate cursor overlay. Links are clickable, even when a URL wraps across lines. Wide characters line up. Apps that clear the screen redraw cleanly.

<img alt="Live terminal pane" width="700" src="https://raw.githubusercontent.com/cablehead/stacks2099/main/changes/v0.3.0/terminal.png">

**Themeable colors.** Pick a terminal palette from the top bar. Themes are plain CSS variables, so adding one is a few lines.

<img alt="Theme picker" width="760" src="https://raw.githubusercontent.com/cablehead/stacks2099/main/changes/v0.3.0/theme.png">

**One top bar.** The top and status bars are merged. New and Actions handles are always visible.

<img alt="Top bar" width="760" src="https://raw.githubusercontent.com/cablehead/stacks2099/main/changes/v0.3.0/topbar.png">

**Faster new clips.** A top-right dropdown creates clips. Type to pick the kind, no mouse needed.

<img alt="New-clip dropdown" width="760" src="https://raw.githubusercontent.com/cablehead/stacks2099/main/changes/v0.3.0/newclip.png">

**Clip actions on Cmd-K.** Rename or close the focused clip from one panel, even over a live terminal.

<img alt="Clip-actions panel" width="760" src="https://raw.githubusercontent.com/cablehead/stacks2099/main/changes/v0.3.0/actions.png">

**Scrollable stack layout.** Each stack lays out as a horizontal strip you can scroll. Alt+L toggles it.

<img alt="Scrollable niri layout" width="760" src="https://raw.githubusercontent.com/cablehead/stacks2099/main/changes/v0.3.0/layout-niri.png">

**Navigate stacks anywhere.** A top-left breadcrumb names the current stack and opens a switcher to jump between stacks or make a new one. It stays reachable when the scrollable layout hides the rail. Alt+\ opens it; Alt+[ and Alt+] cycle.

<img alt="Stacks switcher" width="760" src="https://raw.githubusercontent.com/cablehead/stacks2099/main/changes/v0.3.0/stacks.png">

**Manual clip ordering.** Reorder clips and sort a stack with keyboard chords; order survives live updates.

**Docs.** A new journey.md walks through how the server-rendered terminal came together. A stacks-session skill edits clips on a running session.
