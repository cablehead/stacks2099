# v0.3.0

## Highlights

Server-rendered terminal grid got a major pass. The pty now ships a per-row seqno diff stream with a separate cursor overlay, stable row ids so a scrollback purge skips a full-grid morph, and correct handling of primary/alternate screen flips via a full re-emit. Cells render clickable hyperlinks (including URLs wrapped across logical lines) and fixed-width wide characters, and the morph HUD breaks down rows shipped per patch into added, removed, and changed.

Theming: the terminal palette is now themable through CSS variables, with a theme picker in the top bar.

UI and actions: the top and status bars are consolidated into one bar with visible New and Actions handles, a top-right new-clip dropdown supports keyboard quick-select, and a clip-actions panel (rename, close) opens with Cmd-K even over a focused terminal.

Layout: per-stack niri layout renders sessions as a scrollable strip (Alt+L toggles it), terminals fill the full column height with collapsed nav rails, and panes widen to 100ch.

Clip ordering: fractional position-between ordering with /clip/move and /stack/sort endpoints, client-side reorder, and move/sort chords.

Docs: a journey.md narrative tracing the progression to a server-rendered terminal grid, and a stacks-session skill for reading and editing clips on a running session.
